A.1 Componentes

El proyecto ocupa dos repositorios hermanos, que se clonan uno junto al otro (neuroriemann-quarto/ y neuroriemann/ en la misma carpeta):

Componente Repositorio · ubicación Papel
Libro (Quarto) neuroriemann-quarto · _quarto.yml, index.qmd, parts/, chapters/, appendices/ Texto, ecuaciones y laboratorios
Temario neuroriemann-quarto · temario.toml Estructura del libro y estado editorial de cada capítulo
Simuladores OJS neuroriemann-quarto · simulators/ Fórmulas cerradas en JavaScript para la interacción en el navegador
Entorno Julia del libro neuroriemann-quarto · Project.toml, Manifest.toml Versiones fijadas; enlaza NeuroRiemann.jl por ruta (../neuroriemann/julia/NeuroRiemann.jl)
NeuroRiemann.jl neuroriemann · julia/NeuroRiemann.jl/ Implementación de referencia; los capítulos llaman a sus funciones
Fixtures neuroriemann · fixtures/*.json Resultados de Julia con semilla fija, para la validación cruzada
Validación Python neuroriemann · python/validation/ Recalcula los fixtures con NumPy/SciPy y pyRiemann; no produce resultados del libro
Bibliografía neuroriemann-quarto · bib/references.bib, bib/VERIFICATION.md Solo entradas con DOI, arXiv o ISBN verificados

El código (neuroriemann) es público. Las fuentes del libro se mantienen en un repositorio aparte; lo que se publica de ellas es esta edición web.

A.2 Reproducir

Código, fixtures y validación, desde la raíz de neuroriemann:

# Tests del paquete
julia --project=julia/NeuroRiemann.jl -e 'using Pkg; Pkg.test()'

# Fixtures (semilla fija) y validación cruzada en Python
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. julia/scripts/generate_fixtures.jl
cd python/validation && python3 -m venv .venv \
  && .venv/bin/pip install -r requirements.lock && .venv/bin/pip install -e . \
  && .venv/bin/pytest && cd ../..

Libro, desde la raíz de neuroriemann-quarto (con neuroriemann en la carpeta hermana o indicado en NEURORIEMANN_ROOT para los tests de los simuladores):

# Entorno Julia del libro y tests de los simuladores frente a los fixtures
julia --project=. -e 'using Pkg; Pkg.instantiate()'
node --test simulators/

# Bibliografía, libro y comprobación del sitio
python3 scripts/verify_bib.py
quarto render
scripts/check-site.sh

A.3 Comprobación del entorno

La celda siguiente se ejecuta al renderizar el libro con el motor Julia nativo de Quarto y comprueba que el paquete está disponible:

Código 
using NeuroRiemann, LinearAlgebra

P = [2.0 1.0; 1.0 2.0]
(julia = VERSION, isspd = isspd(P), exp_log_id = expm(logm(P)) ≈ P)
(julia = v"1.12.3", isspd = true, exp_log_id = true)

A.4 Semillas y tolerancias

  • Todo dato aleatorio se genera con StableRNGs.StableRNG, cuyo flujo no cambia entre versiones de Julia; la semilla de los fixtures es 20261103.
  • La tolerancia relativa de la validación cruzada Julia–Python es \(10^{-10}\) en norma de Frobenius, normalizada por \(\max(\|B\|_F, 1)\).
  • isspd considera SPD una matriz simétrica con \(\lambda_{\min} > 10^{-12}\,\lambda_{\max}\) (número de condición menor que \(10^{12}\)); por debajo, la matriz se trata como numéricamente singular.
